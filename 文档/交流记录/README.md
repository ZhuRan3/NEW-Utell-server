## 强制更新时机

1. 复杂会话开始：先读取本端 `AGENTS.md`、当前进度、项目驾驶舱和相关证据。
2. 计划或执行改变阶段、风险、决策或证据时：更新驾驶舱和主交流记录。
3. 会话结束：补齐测试站证据、术语学习卡（若有新词）和下一步。
