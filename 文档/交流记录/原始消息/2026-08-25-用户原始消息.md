一、当前主链路

手机配对/指纹确认
  -> Relay 建立身份与路由
  -> Connector 健康检查通过
  -> READY，开放输入
  -> 手机内存生成 Capture
  -> WSS Relay 转发端到端密文
  -> Relay ACK（只代表路由收到）
  -> Connector 验签、幂等、权威数据库持久接收
  -> 持久接收回执
  -> Pi 解析提案
  -> Connector 校验并事务提交 LogEntry/Event
  -> Projection 按 event_version 下发
  -> 手机当前会话内存展示
  -> Card Command 携带 expectedVersion
  -> 版本冲突拒绝或生成新 Projection

这些核心边界与 PRD 一致，见 PRD 第 4、5 节。

关键规则已经明确：

- Connector 是业务权威端。
- Phone 不持久化 Capture 原文、Outbox、Card 或 Projection。
- Relay 不解密、不保存业务正文、不建立离线业务队列。
- Relay ACK 不等于 Connector 已接收、已提交或已投影。
- 非 READY 禁止输入。
- 未知结果不自动重发。
- Projection 只接受更高版本。
- Card Command 使用 expectedVersion，冲突返回 VERSION_CONFLICT。
- 原文追溯只通过 event_id 在线请求，当前会话内存展示。
