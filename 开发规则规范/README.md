# 开发规则规范

本目录是云 Relay 长期维护的工程规则真源。规则先于实现，契约和故障 harness 先于真实部署。

## 文件索引

- `01-需求对齐与Q&A规范.md`：需求讨论的完整记录格式。
- `02-文档生命周期与中文规范.md`：目录、命名、版本、中文和归档规则。
- `03-架构分层与仓库边界.md`：本端模块和跨端职责边界。
- `04-harness开发与验证规范.md`：契约、模拟器、场景和证据的组织方式。
- `05-测试证据与发布门禁.md`：测试分层、证据包和发布阻断条件。
- `06-安全隐私与数据留存规范.md`：密钥、原文、日志和数据留存的禁止项。

## 执行顺序

```text
需求原文 -> Q&A 对齐 -> PRD/架构更新 -> 契约与 fixtures -> harness 场景
  -> 单测/契约测 -> 集成与本端运行证据 -> 发布门禁 -> 变更记录
```

所有未确认事项必须显式写成“待确认”。不得以默认值、临时 fixture 或 UI 文案替代用户决策。
