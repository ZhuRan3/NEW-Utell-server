# NEW-Utell Server

Utell（油条）云服务器端独立仓库，当前阶段是从零建立工程规范与验证骨架，不直接承接旧项目代码。产品基线来自 `项目总体背景愿景目标/PRD：Utell（油条）第一代智能日志 MVP.md`。

## 当前边界

- Owner：Zhu3xx，负责 Relay 的需求、架构、实现、测试、云上部署、发布和维护；技术栈 Go + Caddy + SQLite（纯 Go 驱动）+ 阿里云（Q-SV-2026-014 已确认）。
- Relay 是安全路由面：身份、二维码配对、公钥登记、撤销、WSS 密文路由、ACK、重连、限流和最小脱敏审计。
- Relay 不读取、不解密、不长期持久化 Capture、Card、Projection 或 Pi 输出；不建立离线业务队列。
- 本仓库不实现手机 UI、PC Connector、Pi Agent 或权威数据库；跨仓库只通过版本化公开契约联调。
